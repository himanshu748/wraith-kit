## Before recording

- Run the documented local commands and the current test suite. Verify the specific clicks in the shotlist before starting capture.
- Use a clean demo store and keep provider mode `none`. If the UI shows current dates, use the documented demo clock/fixtures consistently and say so. Do not conceal an expired or uncertain deadline as a working future reminder.
- Set the viewport and zoom so action text, evidence and controls are readable at 1080p. Move the pointer deliberately; avoid rapid jump cuts that hide a failed action.
- Remove account menus, tokens, local sign-in URLs, unrelated tabs, real source configuration and personal calendar entries from the capture.
- Record hook evidence only from a real Kiro agent operation. A manual terminal invocation is a script demonstration, not proof that the hook fired automatically.
- Keep the raw clips and a small note recording the commit and commands used. Do not publish automatically.
